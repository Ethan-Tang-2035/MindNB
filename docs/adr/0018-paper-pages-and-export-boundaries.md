# 纸页是文档内持久的内容容器与独立输出单位

Status: accepted

手账整理与封面制作需要同一画布上的多张纸页，而且按页导出是首版核心。用户在纸页需求 Q3、Q12–Q17、Q19 中确认：纸页属于当前文档，整棵导图及独立内容具有稳定的纸页归属，越界、调整边界和几何重叠均不自动改变归属；不能复用 ADR-0003 分组框的临时几何包含语义。

编辑中的显示溢出、裁切、自动扩页是逐页设置，三种模式均保留内容；导出以纸页为单位，默认按其边界裁切，也可仅在输出中适配所属内容，不回写正文。页序独立于空间位置，批量图片与多页 PDF 按页序输出；页内跨树关系线保留，跨页关系线只在画布保留，不进入按页输出或整页副本。

这扩展了旧编辑器方案“A4 仅用于导出预览”的边界，但保留 ADR-0006 的多主题画布及 ADR-0014/0015 的查看与内容坐标分离。代价是主树位置、归属变更、保存撤销、资源往返与输出范围必须统一处理；选择这一复杂度以换取移页和批量输出的稳定结果，而不引入独立纸页文档或跨文档引用。

产品基线与验收见 [纸页回归](../../tests/desktop/paper-pages.e2e.ts)。

实现补充（2026-09-13）：带纸页的文档标记 schemaVersion 12，pages 与 rootPosition 持久化；新客户端兼容读取旧文档，旧客户端不保证编辑纸页文档。复制内容重新生成标识并重绑页内线，列表顺序独立于位置。默认输出宽 1080 px；PNG/JPG 使用实际编码预览，PDF 为保留各页比例的栅格多页文档。完整验证见 [纸页回归](../../tests/desktop/paper-pages.e2e.ts)。
