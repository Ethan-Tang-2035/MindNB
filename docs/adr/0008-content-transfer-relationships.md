# 内容移入节点时将关系线归属转给节点

Status: accepted

独立内容移入节点后，原来连接该内容的关系线改连所属节点；再次移出内容时，关系线继续留在节点上，不自动恢复到内容。转换导致的自连线移除，内容归属变化、端点重绑和自连线清理组成一次可撤销的操作。

例如图片 A 连着节点 B，将 A 放入节点 C 后，关系成为 C—B；再把 A 移到画布，C—B 仍保留。若 A 原本连接的就是 C，则嵌入时移除该自连关系，撤销转换可以完整恢复。

此决定避免让节点内部内容继续作为隐形关系线端点，保留关系线在可见节点层级上的含义。代价是移入再移出不构成关系拓扑的逆操作；只有撤销能恢复转换前的关系，用户需要重新连接才能让移出的内容获得关系线。
