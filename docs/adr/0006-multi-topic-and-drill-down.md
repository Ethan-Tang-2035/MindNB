# ADR-0006 多主题无限画布与查看态下钻

## 状态

Accepted

## 背景

现有文档以一个中心主题为根，另有游离节点和画布对象。产品需要在同一张无限画布中表达多个独立主题，并能对节点分支进行最多三级的聚焦查看。将节点内嵌套子画布与查看态下钻混用，会同时引入新的文档层级、保存边界和返回语义。

## 决策

- 多主题作为文档中的多棵独立主题树；每棵树有自己的位置和局部布局。
- 独立主题与游离节点保持不同概念：前者是正式主题树，后者是自由放置的节点或子树。
- 下钻先实现为查看态过滤：只改变可见范围和导航路径，不改变树结构和内容撤销历史。
- 下钻深度最多连续三层；返回恢复该层进入前的视图与选中状态。
- 关系线继续作为独立画布对象，不表达父子结构；跨聚焦范围的关系线隐藏而不删除。

## 理由

该模型复用现有树、游离集合、画布对象和视图持久化能力，同时把结构编辑与查看导航分开。下钻可以先解决大图阅读问题，未来若确实需要节点内独立内容空间，可在不改变当前下钻语义的情况下另立决策。

## 代价

布局、缩略图、导出、迁移和关系引用需要支持多个主题根；主题列表和定位也成为必要的导航能力。独立主题之间不自动磁吸，以避免用户误把视觉靠近理解成结构合并。
