# ADR-0011 暗色纸自动联动浅墨

纸页扩展：[ADR-0019](0019-page-local-paper-and-ink.md) 要求纸页的默认配色适配仅作用于本页，不能把改页纸底写成文档级墨色变化；无纸页时的既有规则保留。

V2 修订（已确认，待实现）：工具界面浅深色跟随系统，独立于纸底及文档墨色。下文浮层 chrome 沿墨色联动的规则被此决定替代；画布文字、描边、纹样的暗纸浅墨规则保留。

纸底早已是文档级覆盖字段（v9 票 04），v14 新增炭黑、黑板墨绿、图纸深蓝等暗色纸后，「暗纸 × 浅色主题（蜡笔米黄、素笺等）」会出现深底配深字的不可读组合。XMind 用「智能配色」做全局联动（按填充深浅自动适配文字色）；笔记类竞品（GoodNotes/Notability）多靠用户自己选配套色模板。单用户产品没有精力逐项手调，可读性又是硬约束，决定做**单向自动联动**。

## 决策

- **应用暗色纸时自动写入墨色覆盖**：所选纸底为暗色（按亮度阈值判定）且当前生效墨色为深色时，自动写入文档级墨色覆盖 = 该暗色纸的配套浅墨；文字、描边、文字垫片、浮层 chrome 沿既有解析链自动跟随。暗色主题（夜航、炭黑岩等）换暗色纸时墨色本已生效，不产生额外覆盖。
- **单向、不自动回滚**：切回浅色纸时不撤销已写入的墨色覆盖——隐式替用户撤销显式状态比「留着多一步手动复位」更反直觉；用户可通过换主题或手动复位恢复。
- **纹样笔画跟随同一联动**：纸型纹样以墨色低透明绘制（ADR-0010），墨色联动后纹样自动变浅色，无需第二套规则。

## 刻意取舍

- 放弃「限制暗纸只配暗色主题」（面板置灰）——组合自由受损、面板规则分叉，且「暗纸 + 深色分支换色」这类部分可读场景无法用整卡置灰表达。
- 放弃「不处理，用户自己负责」——深底深字是可读性硬伤，即使自用产品也会频繁踩中。
- 放弃「双向联动」（切回浅纸自动恢复原墨色）——需要为一次换纸记录额外撤销状态，隐式改动用户显式覆盖，违反「切换主题/纸底只改默认值、不清除显式覆盖」的既有心智。
