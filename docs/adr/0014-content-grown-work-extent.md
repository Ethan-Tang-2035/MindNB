# 按内容增长的工作范围与稳定布局坐标

状态：已接受的 V2 产品方向，待实现。

无限平移容易让用户迷失在空白中，而随窗口重新定位中心主题会让打开格式面板也改变导图位置。按用户确认的编辑器 V2 方案，保留无限逻辑画布，但将可导航的工作范围与内容布局、视图分开：仅内容变化触发范围增长，范围增长和窗口变化不移动已有内容，平移与缩放不制造新空间。

此决策替代 ADR-0001 关于布局以当前窗口中心为基准以及溢出时根锚点让位的做法；保留其“查看不是编辑”的原则，以及 ADR-0006 的独立主题和查看态下钻语义。工作范围随文档和聚焦范围记忆，删除或折叠不立即收缩，避免视图跳动；旧视图数据须兼容读取并转换，不能因缺少新字段而改变文档内容或丢失用户视图。

代价是需要独立处理视图边界、布局坐标及拖动预演，不能复用窗口尺寸充当画布尺寸；取舍是接受这部分复杂性，以换取稳定位置和可预期的导航。

导航边界允许工作范围四周出现视口留白，不要求工作范围填满视口。缩小后的工作范围不强制居中，也不锁定平移轴；“适应窗口”按实际内容居中。极端平移仅保证工作范围仍有一部分可见（每轴最多保留 48 屏幕像素，小视口或小范围相应缩减），这个屏幕余量不写入世界范围或文档几何。否则短轴会无法拖动，旧的大范围还会覆盖实际内容的居中结果。
