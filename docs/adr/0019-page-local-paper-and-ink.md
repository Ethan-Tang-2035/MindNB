# 纸页纸面与默认配色适配仅作用于本页

Status: accepted

用户确认同一文档内每页可单独设置纸底与纸型，并可同时使用浅色纸与深色纸。若直接沿用 ADR-0011 的“换暗纸写入文档级墨色”，修改一页会改变其他页及页外内容，因此纸页覆盖与默认配色适配必须限制在本页作用范围内。

按 Q10、Q18，纸页默认跟随文档，可有自己的纸底 / 纸型；针对实际纸底，仅适配该页默认文字、描边和连线的可读性，纹样及关系线标签底色保持一致，手动指定配色保留。适配不改其他页面、不改全局文档墨色，也不影响独立于纸面的工具界面；画布与导出使用同一效果。

此决策为 ADR-0010/0011 增加纸页作用范围，不改变没有纸页时的既有文档规则。代价是颜色解析需要识别所属纸页，不能只读取文档主题；拒绝把整页换色变成全图重新配色，也不要求用户为每张深色纸手动重设所有默认颜色。

实现补充（2026-09-13）：默认文字针对最终承载底色适配，包括纸面、浅色根节点、纸片底及表格单元格；不能只根据纸色统一切换为白字。显式文字色保持优先。SVG 画布与 PNG/JPG/PDF 共享这一解析规则；数据层不改用户手动色。
