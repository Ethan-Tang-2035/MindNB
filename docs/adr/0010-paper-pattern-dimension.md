# ADR-0010 纸型成为文档级独立维度，与纸底正交

纸页扩展：[ADR-0019](0019-page-local-paper-and-ink.md) 允许纸页独立覆盖纸底 / 纸型并进行本页默认配色适配；无纸页时的文档级规则保留。

用户需要笔记本横线、方格、点阵等画布铺底纹样（调研：GoodNotes/OneNote/Notability 的纸张体系均为「类型 × 颜色」正交组合，且暗色纸是真需求；导图类竞品几乎无人内置纹样）。本产品纸底现状只有 5 种纯色（v9 票 04 的文档级 `paper` 覆盖 + `PAPER_CHOICES`）。若把纸型绑定进主题（每主题固定一套纸型词条），组合数受限、用户无法「牛皮纸底 × 方格」自由搭配；若完全自由又不给主题默认值，主题就失去「一键成套」的价值。决定引入**纸型**作为文档级独立维度，与纸底正交，主题携带默认值。

## 决策

- **纸型 = 文档级独立字段，与纸底正交**：首期词表 `blank（空白，即现状）/ ruled（横线）/ grid（方格）/ secGrid（手账方眼）/ dots（点阵）/ wavyRuled（波浪横线）`；字段缺省 = `blank`，存量文档零迁移。
- **主题携带可选默认纸型**：缺省 `blank`；切换主题只改默认值，文档显式覆盖优先——沿用 v9/v12 既有的「文档覆盖 > 主题默认」解析链。
- **密度两档（疏/密）**：文档级字段，缺省疏；不随主题变化。
- **纹样笔画颜色跟随墨色**：以墨色低透明绘制，不设独立「纹样颜色」控件；暗色纸下的浅墨联动见 ADR-0011。
- **渲染与导出共用一套纹样定义**：画布走 SVG pattern，PNG 导出走 Canvas 等价平铺，保证所见即所得。
- **面板新增「纸底」「纸型」两组控件**：纸型组含「跟随主题」缺省项，与分支形状/线条的「跟随主题」交互惯例一致。

## 刻意取舍

- 放弃「纸型并入主题枚举」——每加一种纸型就要为主题逐个配色搭配，主题数 × 纸型数组合爆炸；正交 + 默认值以零成本拿到全部组合。
- 放弃三档密度与任意行距滑杆——无限画布下密度感知弱，三档与两档的面板成本相同而收益不可感（Notability 的 8 档物理标尺对固定纸张有意义，对无限画布没有）。
- 首期词表不做斜线、十字点网格、双线横线、方巾纹等其余纸型词条——手绘家族一致性优先，词表按需扩充（ADR-0009 同思路：维度先行，词条递增）。
