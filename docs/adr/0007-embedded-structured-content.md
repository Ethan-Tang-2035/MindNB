# 节点内嵌内容采用固定排版与可编辑结构

Status: accepted

为支持图文节点以及可插入的表格、循环图，节点允许拥有内嵌内容，同时保留这些内容独立放置在画布上的用途。节点内部采用固定图文排列，可放多张图片；表格和循环图插入后保留可编辑结构，而非只保存外观图片。

这一决策扩展 ADR-0003 中图片与贴纸仅作为独立画布对象的边界。归属节点的图片随其移动、隐藏、复制和删除；其排版参与节点尺寸计算，不能仅靠把独立图片叠在节点上实现。

取舍是放弃节点内部任意拖放、叠加的子画布，以及静态图片方案的简单性，换取可预测的图文布局和插入后的持续编辑能力。该内容模型不改变 ADR-0006 中查看态下钻的含义。

整个图表可以由节点承载，该节点可以成为独立主题或子节点；图表也可以作为独立画布对象。循环步骤与表格单元格不具有思维导图节点身份，不拥有子树、下钻或外部关系线。这样保留图表局部编辑和自动排布能力，同时避免两套结构层级混在一起；代价是无法把图表内部某一步当作正式分支继续展开。

图片、贴纸、表格与循环图支持在独立放置和节点内嵌之间转换，关系线按 [ADR-0008](0008-content-transfer-relationships.md) 处理。手绘笔迹默认归属于画布，用户选中后可显式放入节点；不根据空间靠近自动建立归属。

内嵌笔迹保留原始笔画，通过双击或“编辑笔迹”进入固定画幅的绘画编辑器，支持继续绘制和整笔擦除；已有节点也可直接新建手绘内容。该编辑器仅编辑笔迹，不承载思维导图节点或独立主题，因而不引入新的文档层级。保留笔画比栅格化更复杂，但保证嵌入后仍能持续修改。
