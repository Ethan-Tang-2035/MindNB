# ADR-0013 彩虹分支改为逐级续轮（有意破坏存量渲染）

现状 `branchColorsOf`（theme.ts）按一级分支序号取色，整棵子树同色（「分支」词条旧定义「同分支同色」）。用户指出彩虹的本义是「每个分支点下面都不同颜色」，现有行为只轮转一次就固定（2025-09-09 第三轮反馈）。决定把取色改为**沿父链逐级续轮**。

## 决策

- **续轮公式**：child i 的色 = (最近显式祖先的基准 + 1 + i) mod 色卡长度；根基准为「无色」，一级分支即经典彩虹（0,1,2…），深层继续转。
- **显式颜色**（节点色/分支换色/「应用到子主题」）：覆盖该节点自身，并作为其后代续轮的新基准（最近显式祖先获胜）；「应用到子主题」等价于把颜色钉到整棵子树。
- **色卡与单色不变**：'mono' 仍全墨色；显式色优先级最高。
- **连线随子节点**：每条连线的颜色用它指向节点的生效色。

## 刻意取舍

- 放弃「分支换色 = 钉死整棵子树」的旧行为——与逐级续轮矛盾；两套语义并存会让「换色后后代为什么还在变色」变成持续困惑。想要整树同色，用「应用到子主题」。
- 放弃「每级重置为 0 起轮」——从父色 +1 起轮保证父子不撞色、兄弟连续不重复，视觉上更像 XMind 的彩虹。

## Consequences

- **存量渲染变化是有意的**：v14 ADR-0010 的「存量等价」红线（R1）对本变更不适用；实施时同步更新 CONTEXT.md「分支」「彩虹分支」「色卡」「分支换色」词条（已于 2025-09-09 grill 定案时更新）。
