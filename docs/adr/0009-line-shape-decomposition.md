# ADR-0009 线形解耦为分支形状 × 线条

对齐 XMind 分支样式要求「任意几何形状 × 任意笔画样式」自由组合（波浪直线、虚线折线、弧线加端点……），而现有 `LineShape = curve | straight | elbow | dashed` 把两者混在一个字段：`dashed` 既是形状又是虚线样式，每新增一种形状都要重复实现一遍虚线。决定拆成两个正交维度——**分支形状**（曲线/直线/折线/圆角折线/弧线）与**线条**（实线/虚线/波浪实线/波浪虚线/无线条），沿既有的三层优先级链（分支头覆盖 → 文档级 → 主题默认）各自独立覆盖。

## 决策

- **`'dashed'` 作为遗留值保持合法**：存量文档不做迁移，读取时归一为「曲线 × 虚线」，新写入一律用新维度。零数据迁移。
- **节点边框不并入此模型**：节点边框线型（实/虚/点）描述闭合盒形描边，与开放连线的形状 × 线条语义不同；维持 `borderLine` 现状，仅扩展线型词表（加手绘双线）与新增独立边框颜色。
- **波浪与渐变各归其位**：波浪属于线条维度（笔画样式），渐变粗细属于粗细维度（基准宽度 + 渐变方向），二者都能与任意分支形状组合。

- **固定粗细与继承分开存储**：分支 `branchTaper='fixed'` 显式关闭文档渐变；字段缺省表示跟随文档。选择固定档位同时写入宽度和 `fixed`，选择跟随时删除两项覆盖。

## 刻意取舍

- 放弃「保持 LineShape 单字段、用命名组合值（`dashedElbow`、`wavyStraight`……）枚举爆炸」——组合值数量 = 形状数 × 线条数，再加维度会平方爆炸；旧值兼容反正都要做，不如一步到位拆开。
