# 文本框与节点保持不同身份，使用显式转换连接两种用途

Status: accepted

画布同时需要独立标题、带文字说明框与可继续扩展的思维导图节点；若仅用零子节点的游离节点承载排版文字，用户会遇到不符合用途的结构设置和节点操作。决定将独立文字及其框形外观作为文本框，与节点保持不同身份；只有用户明确执行“转为节点”时才获得节点能力，普通关系线、空间靠近和当前子节点数量不自动改变身份。

这一选择延续 ADR-0003 的树与画布对象分离，代价是维护两类内容及显式转换，收益是文字排版和思维导图编辑拥有可预测的行为。2026-09-14 需求访谈第一、二轮已确认。

第三轮确认有限双向转换：保留文字、当前外观、位置、关系线和纸页归属，并支持一步撤销；反向转换仅允许没有父节点、没有子节点、没有文本框无法承载的信息的游离节点。旧文档不按外观或子节点数量自动转换。这使转换避免静默丢失结构或内容，代价是部分节点必须先由用户处理专属内容，才能获得普通文本框身份。

文本框不参与节点层级字号、分支配色或子树样式传播；默认颜色的纸面适配沿用 ADR-0019 的作用范围。完整需求及验收见 [文本框回归](../../tests/desktop/text-box.e2e.ts)。
