# MindNB preview / 预览版

Local mind maps, visual notes and illustrated journals, with portable `.mindnb` export.
本地思维导图、可视化笔记和图文手帐，支持 `.mindnb` 可携带文档。

## Signing / 签名

The preview workflow produces unsigned installers. macOS builds are not Apple-notarized. System security warnings may occur. This is not a signed production release.
本流程生成未签名安装包，macOS 未完成 Apple 公证，系统可能显示安全提示。

## Downloads / 下载

Choose the file matching your OS and architecture. `SHA256SUMS.txt` covers installers and the corresponding-source archive. GitHub's automatically generated source archives are not installers.
按系统与架构下载；校验文件覆盖安装包及对应源码包。GitHub 自动生成的源码附件不是安装包。

The interface is primarily Chinese. Back up your vault before upgrading. Automatic updates and concurrent cloud-folder editing are not verified features.
界面以中文为主，升级前备份资料库；自动更新与云文件夹并发编辑尚未验证。
