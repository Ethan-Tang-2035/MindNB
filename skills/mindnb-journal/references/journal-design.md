# 手账编排与验收

适用于第一次规划整册、从长文分配页面或修正拥挤版面。按内容需要取舍，不把建议页数、字体或色彩变成固定模板。

## 页面节奏

- 一页承担一个主要作用，例如解释观点、展示结构、记录观察或填写练习。导图可在一页中解释局部关系，不必让整本册子成为一棵树。
- 连续页面共享标题层级、边距和少量强调色；通过横线、点阵、方格或空白纸变化节奏。纸面纹理与纸张尺寸是不同选择。
- 先安排信息与留白，再放装饰。可爱风可用圆润形状、柔和色彩和少量贴纸；商务、极简或其他风格按用户要求调整。
- 当前渲染顺序中，独立图片位于导图节点之上。全页不透明插画只配合后创建的文本框；导图页使用原生纸纹，避免背景图片盖住真实树。
- 图片生成提示应要求无文字、无伪文字、低对比背景和明确空白区。图片导入后，把可读内容放在原生对象上。

## 内容分配

- 标题长度以真实字体渲染为准。长标题拆成自然短行或调整版面，不为保留装饰压成难读的小字。
- 每个导图节点表达一个短意群，长说明使用相邻文本框；从当前布局能力出发分配空间。
- 原文摘要应简短并标明出处。新增例子、练习和解释标为原创应用，勿将其归给原作者。
- 练习页为实际填写留出空间，使用可编辑占位文字或空白区；示例答案明确标注为示例。
- 大段内容超出容量时增加纸页或精简非必要内容；不能静默截断，也不要假设软件已支持自动分页。

## 预览时检查

| 检查 | 可观察的合格表现 |
| --- | --- |
| 文字 | 中文字符完整，标题／正文有清晰层级，正文能在正常阅读尺寸下辨认 |
| 结构 | 导图连接正确，节点与独立文本身份正确，所有内容属于预期纸页 |
| 排版 | 无正文碰撞与纸页越界，装饰不压字，页面次序清楚 |
| 纸面 | 纹理不干扰阅读，同册风格协调，关键知识不在背景图中 |
| 编辑 | 能修改一段正文；若有导图，能增改一个真实节点并继续保存 |
| 交付 | 最后修改进入可编辑文件及导出图，页数与预览一致，来源可追溯 |

几何检查不能代替视觉查看；预览截图不能代替可编辑源文件。对于整册作品，检查每一页，修改后至少复查受影响页面。
